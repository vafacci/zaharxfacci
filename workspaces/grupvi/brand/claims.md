# Grupvi claims policy

## Allowed
- Study-group chat + project overview + easy invite (link/QR).
- Guest participation without forced personal account (as product principle / reported implemented — don’t invent live metrics).
- Complements existing tools via links (Figma, GitHub, Drive).
- Minimalist Scandinavian visual direction.

## Forbidden
- Invent user counts, institutional partnerships, or performance stats.
- Present earlier ideas (AI summaries, advanced task management) as launched features.
- Treat Telegram as copied brand identity (it was UX reference for chat feel only).
- Invent slogans, channels, or monetization as decided strategy.

## Product facts useful for content (reported — verify before “live” claims)
- Nav: Home · Chat · Profile
- PWA paths discussed: `/`, `/app/`, `/app/join/CODE`
- Domain `grupvi.com` was planned — live status not verified here.
