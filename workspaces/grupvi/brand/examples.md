# Grupvi example captions / lines

Danish, concrete student situations — no invented stats.

## Safe draft lines
1. Ny studiegruppe? Ét sted til chat, medlemmer og projektlinks — uden private sociale profiler.
2. Opret projektet, invitér med link eller QR, kom i gang.
3. Chat + overblik. Jeres Figma, GitHub og Drive kan blive som links — vi erstatter ikke alt.

## Anti-examples
- “Brugt af 10.000 studerende på alle universiteter.”
- “AI der automatisk bestiller jeres opgaver.”
- Enterprise-jargon eller social-network hype.
