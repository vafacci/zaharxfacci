# Grupvi positioning

**Source:** `_knowledge/GRUPVI_Brand_Knowledge.md` (2026-10-15).  
Formerly **StudieChat** (working name).

## What we are
- A digital communication and collaboration space for **study groups**.
- One simple place for group chat, members, project info, deadline, and links (Figma, GitHub, Drive).
- **Supplements** existing tools — not necessarily replaces them.

## Core problem
- New study groups scatter across private chats and apps; connecting via private social profiles is awkward.

## Core principle
- Easy to create a project, invite the group, and start — without heavy setup.

## What we are not
- Not another social network.
- Not heavy enterprise project management.
- Not FACCI AGENT.

## Open
- Formal mission, revenue model, app-store launch timeline, user counts.
