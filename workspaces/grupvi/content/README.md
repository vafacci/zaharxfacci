# Content hub

Her samler I **alt content-arbejde** for Grupvi: idéer, skudlister, captions, links til råfiler/optagelser.

Aldrig auto-publish. Ingen secrets.

## Filer
- `ideas.md` — idéer + locations
- `shoot-list-v1.md` — når I filmer (opret ved behov)

## Mappenorm (valgfri senere)
- `raw/` — links eller noter til rå optagelser
- `published/` — hvad der er postet + dato/kanal
