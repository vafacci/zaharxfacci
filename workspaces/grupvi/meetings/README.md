# Møde-arkiv

Alle møder (ikke kun søndag): agenda → resume → beslutninger → **uddelte opgaver**.

1. Kopiér [`../product/meeting-template.md`](../product/meeting-template.md)
2. Gem som `YYYY-MM-DD.md`
3. Spejl aktive opgaver i [`../tasks/BOARD.md`](../tasks/BOARD.md)

Ældre pointer: `product/meetings/` peger hertil.
