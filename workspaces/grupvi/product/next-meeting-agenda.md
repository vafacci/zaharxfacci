# Grupvi — næste møde (agenda)

**Cadence:** Lige nu typisk søndag — ikke en permanent regel.  
**Grundlag:** [alignment-2026-10-29.md](./alignment-2026-10-29.md) · [operating-overview.md](./operating-overview.md)  
**Rækkefølge dette møde:** koncept → app-MVP-check → landing-scope → content-skudliste → møde-arkiv/opgaver. Monetisering *efter* gratis brug.

Efter mødet: kopier [meeting-template.md](./meeting-template.md) til `meetings/YYYY-MM-DD.md` og udfyld resume + **uddelte opgaver**.

## 1. Koncept-klarhed (15–20 min)

Mål: én fælles sætning + hvad MVP *ikke* er.

- [ ] Bekræft one-liner: “Ét simpelt sted til studiegrupper: chat, medlemmer, projektinfo, deadline og links.”
- [ ] Kerneloop: opret projekt → invitér (link/QR) → chat + home-overblik → brug eksisterende tools via links
- [ ] Explicit **out of MVP**: tung opgavestyring, AI i appen, erstatning af Figma/GitHub/Drive, betaling
- [ ] Notér åbne produktspørgsmål (max 3) — ikke blokér kodning

**Output:** `mvp-scope.md` → checkpoint A i [operating-overview.md](./operating-overview.md)

## 2. App-MVP-check (20–25 min)

Live: [studiechat.vercel.app](https://studiechat.vercel.app/) · kode: `grupvi-app`

- [ ] Join via invitation uden privat social login?
- [ ] Home + Chat + Profile stabile nok til demo?
- [ ] Top **5** bugs/huller før “klar til demo-grupper”
- [ ] 1–2 pilot-grupper udpeges (navne uden for vault hvis privat)

**Output:** `mvp-gaps.md` → checkpoint B

## 3. Landing — hvad siden skal være (10–15 min)

Brug anbefalingen i operating-overview (hero, problem, 3 fordele, 3 trin, CTA — intet pricing).

- [ ] Enig i v1-scope (ja/nej + evt. 1 ændring)
- [ ] Domæne: Vercel nu / `grupvi.com` senere
- [ ] Hvem bygger + deadline

**Output:** ejer + deadline på landing v1 → pejler checkpoint D

## 4. Content-skudliste (10–15 min)

| Scene | Hvor | Viser |
|---|---|---|
| Ny gruppe, akavet start | Campus / bibliotek | Problemet |
| QR / invite | Bord + telefoner | Nem invitation |
| Chat + deadline | Gruppebord | Kerneloop |
| Links til Drive/Figma | Samme | Supplérer tools |
| Kort talking-head | Rolig baggrund | “Ingen privat follow” |

- [ ] Vælg 2–3 scener til første batch
- [ ] Ansvarlig + dato

**Output:** `content/shoot-list-v1.md` når I er klar til at filme

## 5. Møde-arkiv + opgaver (5–10 min)

- [ ] Bekræft: arkiv = **alle møder**, agenda/noter/resume/**uddelte opgaver**
- [ ] Ikke en Grupvi-app-feature
- [ ] Næste møde starter med status på opgaver
- [ ] Udfyld opgavetabel i mødefilen inden I går

## Parkeret

- Monetisering / data-salg  
- Fast SoMe-kanal  
- Andre koncepter som hovedspor
