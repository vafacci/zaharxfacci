## HQ-modellen

```text
tasks/       ← overblik + todos + checkpoints
product/     ← redesign / polish / bugs (appen)
marketing/   ← budskab, landing-forbedringer, kanaler
content/     ← film, captions, assets
business/    ← penge senere (parkeret)
meetings/    ← alle møder + uddelte opgaver
brand/       ← brand pack
```

Bland ikke: **product** = kode/UX i appen. **marketing** = hvordan I fortæller det. **content** = det I filmer/poster. **business** = hvordan I *senere* tjener penge.

## Anbefalet rækkefølge (nu)

1. **Product polish** — få UI til at se færdigt ud (I redesign’er; ikke nye mega-features)
2. **Tasks board** — hold max ~7 aktive opgaver synlige
3. **Content hub** — saml idéer/locations; film når polish er synlig
4. **Marketing** — finjustér landing ift. det I faktisk viser i appen
5. **Business** — kun et notat; gratis først
6. **Møder** — resume + uddelte opgaver → spejl til `tasks/BOARD.md`
