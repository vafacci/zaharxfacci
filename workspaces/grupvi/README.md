# Grupvi — arbejds-HQ (FACCI vault)

**Produktet findes allerede:** app + landing på [studiechat.vercel.app](https://studiechat.vercel.app/)  
Eksempel-projekt: [/app/project/liblpm](https://studiechat.vercel.app/app/project/liblpm) (“design a brand”)  
App-kode: allowlist `grupvi-app` (Desktop `KARRIERE/studiechat`)

Denne mappe er **ikke** “byg appen forfra”. Det er jeres **samlingssted for at drive Grupvi videre**: opgaver, content, marketing, business, møder, redesign.

## Rum

| Mappe | Formål |
|---|---|
| [`tasks/`](./tasks/) | Opgaver / todos / checkpoints — start her til overblik |
| [`product/`](./product/) | App: redesign, UX, bugs, MVP-gaps (produktet) |
| [`marketing/`](./marketing/) | Landing, budskaber, kanaler, kampagner |
| [`content/`](./content/) | Film, captions, skudlister, assets (rå + færdige) |
| [`business/`](./business/) | Fremtidig monetisering — **parkeret**, ikke blocker |
| [`meetings/`](./meetings/) | Alle møder: agenda, resume, uddelte opgaver |
| [`brand/`](./brand/) | Brand pack + knowledge |

## Sådan arbejder I

1. Møde → opgaver lander i `tasks/BOARD.md` + mødefil i `meetings/`
2. Arbejde sker i det rigtige rum (product / marketing / content / …)
3. Afkryds checkpoints på boardet — så I kan se processen over tid

Se [`tasks/BOARD.md`](./tasks/BOARD.md) og [`product/operating-overview.md`](./product/operating-overview.md).

**Partner UI:** [/partner/grupvi](/partner/grupvi) (live: https://zaharxfacci.vercel.app/partner/grupvi) — fokus, opgaver, noter + **Ressourcer** (fælles links/dokumenter)

Do not store secrets here.
