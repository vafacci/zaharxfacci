# AUTIQ brand pack

Curated project knowledge for relevant content. The weekly content loop reads this pack before writing briefs/captions.

| File | Role |
|---|---|
| `voice.md` | Tone and caption craft |
| `positioning.md` | What we are / are not |
| `audience.md` | Who we write for |
| `claims.md` | Allowed vs forbidden claims |

**Rules**
- Keep this pack short and owner-approved.
- Do not dump raw ChatGPT chats here — curate first.
- No secrets, API keys, or private customer PII.
- Missing/thin files → weekly loop blocks calendar write (brief explains the gap).
