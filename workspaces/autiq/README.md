# AUTIQ brand workspace (FACCI-owned)

Allowlisted sandbox for AUTIQ content ops inside FACCI.

- `content/` — captions, calendars, outlines (editable by FACCI developer/marketing path)
- `brand/` — **brand pack** (voice, positioning, audience, claims, examples, glossary) — required for the weekly content loop

Image generation stays in the separate Image Studio app (`imagegen`) via tool adapter — this workspace does **not** contain Comfy workflows.

Do not store secrets here.
